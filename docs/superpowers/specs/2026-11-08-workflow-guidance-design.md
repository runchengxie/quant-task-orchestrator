# Workflow guidance and evidence exploration

The user approved clearer responsible-system terminology, a capability library, human-readable workflow timeline, actionable recorded recovery guidance, real flow acceptance, comparable economic results and sustained read-only shadows.

Use the existing vanilla bilingual UI and read-only interfaces. Public projections must exclude strategy settings, private paths and raw research content. Technical detail remains available. Suggested actions never authorize submission, approval, cancellation or promotion.

Prefer recorded Owner authority and retained artifact verification over recomputation. Existing research mechanism success must remain distinct from formal economic admission. Standard economic comparison requires identical fully known basis: data, universe, benchmark, costs, execution semantics, metric definitions, dates, currency and return frequency. Missing basis is a blocking reason, including when both sides omit the same field. Inputs are externally hash-pinned; this proves byte identity, not independent provenance or financial truth. Ratios are not percentages; drawdown is a positive loss fraction.

Shadow history reads bounded, regular, non-symlink assessment records; explicit configuration pin separates cohorts. Measure actual wall duration and record UTC observation timestamps. Legacy timing remains unknown. Rapid repeated success does not establish sustained stability; seven observations across seven UTC dates and at least seven days are minimum observational coverage, never production cutover authorization. No timers, production aliases, live GUI service or model calls change.

Implementation consists of: public terminology and recorded guidance; standalone strict economic-result comparison contract and CLI with synthetic examples; read-only shadow summary and bounded real repetitions; strictly read-only retained research artifact acceptance. Alternative of inferring missing metrics from engineering success is rejected; a new workflow engine is unnecessary.
